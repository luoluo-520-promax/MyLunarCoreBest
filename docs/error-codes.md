# 业务错误码手册（摘要）

客户端优先看各协议 `retcode`；`0` 一律成功。下列为跨模块常用码与处理建议。

## 通用

| retcode | 含义 | 客户端建议 |
|---------|------|------------|
| 0 | 成功 | — |
| 1 | 未登录 / 参数非法（依协议） | 回登录或提示重试 |
| 2 | 业务条件不满足 | Toast 具体文案 |

## 登录会话（PlayerLogin）

| retcode | 含义 | 客户端建议 |
|---------|------|------------|
| 0 | 成功 | 保存 `session_token` / `session_crypto_key`，启用 KCP AES-GCM + HMAC |
| 2 | 密码错误 | 提示重试 |
| 3 | 账号封禁 | 联系客服 |
| 4 | 账号不存在 | 引导注册 |
| 5 | 内部错误 | 稍后重试 |
| 6 | 服务器满员 | 排队/换服 |
| 7 | Token 无效 | 重新账密登录 |
| 8 | 登录限流 | 退避重试 |
| 9 | **协议版本不兼容**（`wire_version` &lt; 2） | 强制更新客户端 |
| 10 | **客户端资源包过旧**（`client_res_version` &lt; `ClientRequiredVersions.minClientResVersion`） | 按 `client_update_url` 强制更新资源/整包 |

## 组队 Party（120–129）

| retcode | 含义 |
|---------|------|
| 2 | 已在队伍中 |
| 3 | 不在队伍中 |
| 4 | 非队长 |
| 5 | 目标忙碌 |
| 6 | 队伍已满 |
| 7 | 未找到 |
| 8 | **非权威节点**（跨服）：应路由到 `ownerNodeId` 再试 |

## 公会

| retcode | 含义 |
|---------|------|
| 2 | 参数非法 |
| 3 | 未加入公会 |
| 4 | 已有公会 / 商店条件 |
| 5 | 公会战赛季不可用 |

## 家园

| retcode | 含义 |
|---------|------|
| 1 | 未知基建/家具 |
| 2 | 未放置基建 / 互访非法 |
| 3 | 入驻槽满 |
| 4 | 家具数量上限 |
| 5 | 无产出可领 |

## 匹配 / 竞技场

| retcode / reason | 含义 |
|------------------|------|
| illegal_state | 会话状态不允许进入匹配 |
| mode=10 | 异步竞技场，服务端用 ELO 分段 |

## 邮件

| retcode | 含义 |
|---------|------|
| 2 | 邮件不存在 |
| 3 | 已领取 |
| 4 | 领取失败 |

## IAP

| retcode | 含义 | 客户端建议 |
|---------|------|------------|
| 2 | 订单不存在/不可用 | Toast 后重新下单 |
| 3 | 玩家不匹配 / 限购 | 提示限购 |
| 5 | 渠道验签失败 | 展示渠道错误；可重试一次 |
| 6 | 发货失败 | 保留订单，稍后 confirm |
| 7 | 重放拒绝 | 提示已到账，拉余额 |

## 切服迁移

| retcode | 含义 | 客户端建议 |
|---------|------|------------|
| 0 | 本机可进入 | 直接 EnterScene |
| 3 | 缺目标地址 | 稍后重试 / 回登录 |
| 4 | 跨节点重定向 | 断线连 `redirectHost:port` + ticket |
| 7 | Zone 排水中 | 排队提示 |
| 8 | 迁移限流 | 退避 1–2s |
| 9 | 重试耗尽 | 回登录选服 |

## 公会战

| retcode | 含义 | 客户端建议 |
|---------|------|------------|
| 0 | 成功 | — |
| 5 | 赛季不可用 | 提示赛季未开 |
| 20 | 客户端能力不足 | 强制更新 |

完整协议字段见 `docs/protocol-docs.md` 与各 `*_system.proto`。新增错误码时同步本手册与客户端表。

## Postman / Insomnia 环境变量示例

```json
{
  "baseUrl": "http://127.0.0.1:8080",
  "internalToken": "dev-internal-token",
  "adminUser": "admin",
  "adminPass": "<local>",
  "traceId": "{{$uuid}}"
}
```

常用头：

- `X-Internal-Token: {{internalToken}}`
- `X-Trace-Id: {{traceId}}`

健康检查：`GET {{baseUrl}}/actuator/health`
